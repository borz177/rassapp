# Напоминание об оплате за три дня

В настройках «Интеграции → WhatsApp → Рассылка» добавлен независимый
переключатель «За 3 дня до оплаты». Значение — `reminderDays: -3`, по умолчанию
не включается. Остальные значения сохраняются: `-1` — за день, `0` — в день,
`1` — просрочка. Все варианты можно сочетать, время отправки общее.

Добавлен отдельный необязательный шаблон `templates.threeDays`: редактирование,
сброс и предпросмотр работают как у прежних шаблонов. Если в старых настройках
его нет, сервер использует новый текст по умолчанию, а не шаблон «Завтра».
На телефоне четыре кнопки выбора шаблона расположены в два ряда, на широком
экране — в один. Каждая кнопка имеет высоту не меньше 44 px.

Планировщик поддерживает встроенный WhatsApp и Green API через прежний
`waTransport`. Оплаченные суммы вычитаются прежним FIFO-расчётом, полностью
оплаченные платежи пропускаются. Настройка клиента об отключении уведомлений,
время рассылки и интервал повторов просрочки продолжают действовать.

На клиента собирается одно сообщение. Если среди выбранных платежей есть
дата через три дня и другие будущие даты, для каждого срока формируется свой
блок с соответствующим шаблоном, датой и суммой. Старый долг указан только
в первом блоке. Будущая сумма не прибавляется к блоку «Сегодня». После успешной
отправки отмечаются сработавшие платежи; при ошибке транспорта отметок нет.
Повтор в тот же день пропускается по прежнему `lastNotificationDate`.

Текст и расчёт сообщения вынесены в чистый модуль
`server/whatsappReminderContent.js`; его нужно выкладывать вместе с cron-файлом.
Сравнение 12 сценариев без нового варианта со старой реализацией дало одинаковые
сообщения и суммы. Неиспользуемая клиентская функция `processDailyReminders`
также поддерживает новый срок; в ней исправлен знак дня для варианта «За день».

Бесплатная проверка без реальной отправки сообщений:

```sh
TZ=Europe/Moscow node -r ./scripts/no-paid-ai.cjs --test server/whatsappReminderContent.test.js
env -u ELECTRON_RUN_AS_NODE ./node_modules/.bin/electron scripts/check-whatsapp-reminders-ui.cjs
npm run build
```

Тест планировщика исполняет настоящий код cron в изолированном окружении:
БД, транспорт WhatsApp и время подменены. Проверены оба провайдера, частичная
и полная оплата, выключенные уведомления, ошибка отправки, повтор, разные
сроки одного клиента, границы года и високосного февраля. UI-прогон проверяет
включение, локальное сохранение и повторное открытие, старые пользовательские
шаблоны, предпросмотр и ширины 320/390/430 px. Внешние запросы запрещены.
Рабочий cron и реальную доставку при разработке не запускали.
