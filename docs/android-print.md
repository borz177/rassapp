# Печать договоров в Android

Начиная с APK 1.1.3 (versionCode 5) кнопка «Печать» передаёт готовый PDF
в системную печать Android. Пользователь выбирает принтер или «Сохранить как PDF».
Браузер, Electron и iPhone PWA сохраняют прежние способы печати.

В старом APK системного моста нет: показываются предложение обновить приложение
и кнопка «Сохранить PDF». Устанавливать обновление нужно поверх приложения,
с прежней подписью, без удаления приложения.

## Устройство

- `src/androidPrint.ts`: файл в закрытом `Directory.Cache/print-jobs`, случайное
  имя; удаление после закрытия системного диалога, отмены или ошибки.
- `FinuchetPrintPlugin`: принимает только PDF из этого каталога; проверяет
  канонический путь, заголовок PDF и размер (до 40 MiB). Никаких новых разрешений.
- `PdfPrintAdapter`: читает число страниц и копирует исходный PDF вне UI-потока;
  кириллица и вёрстка сохраняются. Как в Android `PrintFileDocumentAdapter`,
  передаёт полный документ и `PageRange.ALL_PAGES`; выбранные страницы извлекает
  системный spooler. `onFinish` означает закрытие окна, а не физическую печать.
- При аварийном закрытии приложения старые временные PDF удаляются при следующем
  запуске плагина через 24 часа. Приложение не отправляет PDF на внешний сервер;
  дальнейшая передача зависит от выбранного пользователем сервиса печати.

## Бесплатные проверки

Запустить Vite (`npm run dev`, обычно порт 3000), затем:

```sh
node scripts/check-android-print.cjs
# Для macOS сбросить ELECTRON_RUN_AS_NODE, если он задан средой:
env -u ELECTRON_RUN_AS_NODE npx electron scripts/check-ios-pwa-print.cjs
env -u ELECTRON_RUN_AS_NODE npx electron scripts/check-desktop-print-controls.cjs
env -u ELECTRON_RUN_AS_NODE npx electron scripts/check-contract-print-template-ui.cjs
```

Для другого порта задать `PRINT_TEST_PORT`. Инструментальные тесты Android требуют
эмулятор API 35, английский язык системы и локальный Vite на порту 3002,
доступный из эмулятора через `http://10.0.2.2:3002` (`--host 0.0.0.0 --cors`).
На эмуляторе не должно быть файла `Downloads/rassapp-print-test.pdf`.
Используются синтетические документы и заблокированные вызовы API/ИИ.

```sh
bash android/gradlew -p android :app:connectedDebugAndroidTest
```

Проверяются ограничение доступа к файлам, реальная кнопка предпросмотра,
системный PrintSpooler, отмена и повторная печать, сохранение двухстраничного PDF.
Физический принтер этим тестом не проверяется.

## Выпуск

Собрать web, выполнить `npx cap sync android`, затем `:app:assembleRelease`.
Использовать прежний закрытый signing keystore, не включать его в Git.
Перед публикацией сравнить SHA-256 сертификатов APK и проверить versionCode.
Сохранить резервные копии текущего публичного APK, исходников и web-сборки.
Обновить `server/downloads/finuchet.apk` новым подписанным артефактом.
Публичный `/downloads/finuchet.apk` публикуется отдельно: штатный frontend deploy
исключает downloads. Сначала атомарно заменить публичный файл и проверить его
хеш, затем выкатывать код с `LATEST_ANDROID_VERSION_CODE = 5` штатным скриптом.
