# Окна прибыли в кассе

Карточки «Получено» и «Выплачено» открывают отдельные `CashProfitSheet`.
«Получено» показывает начисления, «Выплачено» — только адресные выплаты прибыли.
Возврат капитала не является выплатой прибыли. Это действует для менеджера
и для выбранного инвестора либо суммы инвесторов счёта.

В «К выводу» показана сверка:

`получено − выплаты − прочие расходы − отдельно списанные скидки = к выводу`.

Строка отдельно списанных скидок появляется только при наличии таких расходов.
Сверка открывает соответствующую вкладку/фильтр. Во вкладке «Расходы» доступны
«Все», «Выплаты», «Скидки», «Прочие». Строки раскрываются без перехода на новый
экран; детали показывают счёт, договор, полученную оплату, сумму исходной записи,
долю и комментарий, когда они есть. «Открыть договор» ведёт сразу в детали
договора у клиента; возврат сохраняет открытое окно прибыли и раскрытую строку.

`src/cashProfitLedger.ts` строит строки и суммы одним проходом. Формулы прибыли
и распределения долей использует существующие, из `shared/profit.js` через
`src/utils.ts`. Денежные записи не изменяются. Предыдущие скидки без
`discountFromProfit` сохраняют прежнюю формулу.

Скидка при полном погашении хранится в платеже и уже учтена `moneyInProfit`.
В фильтре она показана с меткой «Учтено в начислениях»; доступный остаток второй
раз не уменьшает. Отдельная запись расхода «Скидка клиенту» является отдельным
списанием. Выплата с устаревшим флагом `fromProfit` учитывается один раз как выплата.
Погашение с нулевой доплатой и скидкой тоже учитывается, включая отмену ранее
начисленной прибыли. Совместные договоры приходят разложенными через `moneySales`;
идентификаторы строк включают договор, счёт, платёж и получателя.

Периоды кассы следуют местному календарю, включая ночные платежи, переход через
полночь и дни перехода на зимнее/летнее время. Кнопки предустановленных периодов
обновляют границы при следующей отрисовке; произвольные даты остаются выбранными
пользователем.

`EXPENSE_LOCAL_API=http://127.0.0.1:5001 node --test tests/*.test.mjs server/ai/discountProfit.test.js`,
`npm run build`, `npx tsc --noEmit -p .` (13 прежних ошибок). Отдельная проверка
в Electron: обе группы карточек, детали, фильтры, сверка, сохранение клиента
под окном, анимация закрытия, аппаратный «Назад», мобильная и тёмная темы.
