# Печать договора из установленной PWA на iPhone

Просмотр документа — `components/PrintPreview.tsx`. В обычном браузере кнопка
вызывает `iframe.contentWindow.print()`. Этот вызов не даёт результата/события
успеха, по которым можно надёжно распознать молчаливый отказ платформы.

Для iPhone/iPad с запуском с экрана «Домой» используется отдельный путь:

1. При открытии договора заранее собирается локальный PDF тем же
   `contractPdfBlob`, что и для обычной выгрузки. Содержимое, личный шаблон и
   разбиение страниц не собираются заново другим алгоритмом.
2. До готовности файла кнопка показывает «Готовим…».
3. Нажатие «Печать» синхронно вызывает `navigator.share({files})` с готовым PDF.
   В системном меню пользователь выбирает «Напечатать».
4. Отмена меню не считается ошибкой. При отказе показана ошибка и ссылка
   «Сохранить PDF»; ошибка подготовки допускает явный повтор.

Передача файла другим приложениям начинается только по явному нажатию, не при
открытии просмотра. Сервер, ИИ и внешний конвертер не участвуют. Временная ссылка
на PDF освобождается после закрытия. Автопечать не открывает системное меню PWA.

Подключено к печати договора из списка/карточки клиента, после оформления,
пустого бланка и к просмотру уже готового PDF. Другие HTML-документы без
переданного `preparePdf` продолжают использовать существующий путь печати.
Safari во вкладке, Android и нативная сборка этим переключением не затронуты.

Проверки: `node -r ./scripts/no-paid-ai.cjs --test tests/printEnvironment.test.mjs`,
`env -u ELECTRON_RUN_AS_NODE ./node_modules/.bin/electron scripts/check-ios-pwa-print.cjs`
(нужен Vite на localhost:3000). Проверки с подменой окружения и системного меню
не заменяют проверку AirPrint на физическом iPhone с установленной PWA.

После выкладки: обновить PWA, открыть договор и нажать «Печать», выбрать
«Напечатать», отменить печать и вернуться к договору; проверить личный шаблон
на несколько страниц и обычный Safari.

Ограничение активации: [WebKit: User Activation API](https://webkit.org/blog/13862/the-user-activation-api/),
[Web Share API](https://www.w3.org/TR/web-share/).

## Кнопки предпросмотра в Electron

`.shell-window-head` исключена из области перетаскивания через
`-webkit-app-region: no-drag`. Отступ от системных кнопок Mac/Windows действует
при любой ширине окна, включая ширину меньше 768px. Это общий класс шапки
просмотра печати и документов; обычный сайт этим оформлением не затрагивается.

Проверка: `env -u ELECTRON_RUN_AS_NODE ./node_modules/.bin/electron scripts/check-desktop-print-controls.cjs`.
Она проверяет нажатия мышью, возврат фокуса из iframe и закрытие HTML/PDF,
геометрию Mac и Windows при 1040px и 620px. Разметка Windows проверяется на Mac,
не является проверкой на физической Windows-машине. ОС-печать не запускается.

[Electron: draggable regions перехватывают нажатия](https://www.electronjs.org/docs/latest/tutorial/custom-window-interactions).
