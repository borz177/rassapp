# Расшифровка остатка в обороте

Открывается с главной страницы: «В обороте» → «Остаток».

Формула сохраняется: деньги на выбранных счетах + долг клиентов − внешний
капитал − полученная невыведенная и ожидаемая прибыль владельца и инвесторов.
Это остаток распределения, а не доступные наличные и не автоматически личный
капитал владельца.

`src/turnoverBreakdown.ts` использует `saleMoneyIn`: пометки скидок доходят до
общего `moneyInProfit`. Расчёт скидок живёт в `shared/profit.js`; второй формулы
прибыли в расшифровке нет. Прежние скидки без `discountFromProfit` сохраняют
прежнее правило.

`src/turnoverRest.ts` раскладывает остаток по записям, используя суммы прибыли,
списаний из прибыли и внешнего капитала из основного расчёта. Начальные остатки,
поступления, расходы, изъятия и движение магазина сохраняют свои знаки.
Выплата прибыли уменьшает и деньги, и обязательство по прибыли, поэтому её
влияние на остаток обычно нулевое и второй раз она не вычитается.

Для договора сопоставляются поступления + долг − прибыль + влияние явно
связанных расходов. Связь — `saleId` либо точный идентификатор закупа
`exp_sale_<saleId>` / `exp_sale_<saleId>__<accountId>`. Совпадения суммы или
названия недостаточно. Части совместного финансирования сверяются отдельно
по счетам. Товар со склада и закуп у поставщика подписываются как особые
источники; они не объявляются ошибкой из-за отсутствия прямого закупа.

Разница между остатком и суммой объяснённых строк показывается отдельно.
Строки договоров с несопоставленным закупом и несовпадение баланса счёта с
доступными операциями требуют проверки. Это не доказательство ошибки:
например, импортированный начальный договор может не иметь расхода закупа.
Даже при нулевой итоговой разнице строки для проверки видны — их суммы могут
компенсировать друг друга. Округления выделяются отдельно.

В окне есть формула, фильтр причин, раскрытие исходных расходов и переход к
исходному договору. Начальный остаток и внешний капитал отмечены расчётными
строками. Список загружается постепенно. Проверка только читает данные;
исправления записей и переносы не выполняются.

Проверки:

```sh
node --test tests/turnoverBreakdown.test.mjs server/ai/discountProfit.test.js
npm run build
npx tsc --noEmit -p .
```

Дополнительно проверен интерфейс через Electron: открытие с главной,
раскрытие формулы, расхода и договора, фильтр, возврат, мобильная ширина и
тёмная тема. Production в рамках этого изменения не обновлялся.
