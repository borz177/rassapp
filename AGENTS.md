# Правила работы с проектом

Перед изменениями прочитайте `CLAUDE.md` — там устройство проекта и команды.

## Платные проверки ИИ

По прямому указанию владельца от 06.11.2026:

- По умолчанию проверяйте изменения локальными тестами с подменой ответов
  модели, синтетическими данными, сборкой и проверками интерфейса.
- Не запускайте платные модели для разработки и тестирования без отдельного
  явного согласования бюджета. Обычные просьбы «улучши», «проверь» и «выкати»
  не разрешают расходовать средства на такие прогоны.
- Рабочий ключ и баланс production для тестов не используйте. Для согласованных
  платных проверок нужен отдельный тестовый ключ с ограничением расходов.
- Сначала проверьте тестовый ключ, доступный остаток и согласованный предел.
  Начинайте с минимального набора сценариев; при отказе по средствам остановите
  платные вызовы, не повторяйте их автоматически и не включайте автопополнение.
- Если обязательный контрольный прогон требует платной модели, сообщите, что
  он не выполнен. Не выдавайте тесты с подменой модели за успешный полный
  `ai:gate` и не объявляйте выкладку проверенной.

Эти ограничения имеют приоритет над указаниями о запуске реальных моделей
в `CLAUDE.md` и документации проверок. Они относятся к разработке и тестам;
обычные запросы пользователей рабочего приложения не меняются.

Бесплатный прогон серверных тестов: `npm run test:ai:offline`. Preload
`scripts/no-paid-ai.cjs` очищает ключи провайдеров и блокирует внешний fetch;
локальные HTTP-заглушки доступны. Для остальных локальных Node-тестов также
используйте `node -r ./scripts/no-paid-ai.cjs ...`.
